门店边缘采集器

1. 需要本机已安装 Python 3.8 或更高版本。
2. 把整个目录放在门店一台一直开着的电脑上，这台电脑要能访问店内交换机，并且能访问总部管理端。
3. config.json 里已经写好总部地址和 Token。请把 devices 改成店内真实设备，例如：
   {
     "name": "核心交换机",
     "ip": "192.168.1.1",
     "device_type": "switch",
     "community": "你的团体字",
     "snmp_port": 161
   }
4. SNMP 团体字只留在这台电脑上，不会上传到总部。
5. Windows 双击「启动采集器.bat」。Linux 执行：bash run.sh
6. 设备可以不填 vendor，采集器会按 sysObjectID 识别华为、华三、思科、锐捷和 Linux，并用标准 IF-MIB 读端口。识别失败时按通用 OID 再试一次。
7. 总部暂时连不上时，数据写在同目录的 spool 文件夹，恢复后自动补报。不要在采集器运行时删掉 spool。
8. 回到总部「门店」页面，采集器应变为在线。服务器资源不经过本采集器，请在每台服务器上安装 Agent。
